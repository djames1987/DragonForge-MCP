# C-010A — MCP 2026-07-28 wire binding and compatibility
Authority: owner DEC-001 modern-only. Normative sources: https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning , /basic/transports/stdio , /basic/transports/streamable-http , /server/tools . Source reviewed 2026-10-22. This supplement does not alter the official schema. Implementation-specific authentication and grants are DragonForge policy, not claims about MCP core.

## Request rules
Stateless JSON-RPC 2.0 with every request carrying params._meta["io.modelcontextprotocol/protocolVersion"]="2026-07-28", clientInfo {name,version} and clientCapabilities {}. No initialize and no Mcp-Session-Id; server/discover mandatory. ClientInfo is untrusted descriptive metadata, not credential proof. Server-initiated JSON-RPC requests prohibited; use input_required if subsequently supported. Initial advertised server capabilities: tools only, with listChanged=false until subscriptions/listen actually implemented. No unsupported resources, prompts, sampling, elicitation, tasks, extensions or notifications advertised. Discovery and call filtered per authenticated client.

HTTP: POST one JSON-RPC message per request to loopback /mcp. Require Content-Type application/json and Accept application/json, text/event-stream; exact Host and Origin allowlist; Origin invalid = 403. Require MCP-Protocol-Version header matching body _meta; Mcp-Method header must match method; Mcp-Name mirrors params.name for tools/call. Header mismatches = 400 (HeaderMismatch); unsupported version = HTTP 400 JSON-RPC -32022 with data.supported ["2026-07-28"]; unsupported RPC method = HTTP 404 JSON-RPC -32601. For successful request return 200 application/json one object, or request-scoped SSE if implemented; core server does not open GET stream, no sessions. A notification POST, if supported, follows official 202/no response; no core HTTP client notification is required for this revision. HTTP cancellation by closing response stream. Host check is DragonForge additional constraint.

STDIO: newline-delimited UTF8 JSON-RPC messages, stdout protocol only, stderr diagnostic only; method/version in body only, never transport headers; notifications/cancelled references request ID and suppresses later response. STDIO bridge MUST authenticate its explicitly enrolled client to gateway independently, not use clientInfo as identity.

## Normative positive transcripts
Valid HTTP request, where Authorization is DragonForge local credential:
```http
POST /mcp HTTP/1.1
Host: 127.0.0.1:8765
Origin: http://127.0.0.1:8765
Authorization: Bearer <enrolled-client-token>
Content-Type: application/json
Accept: application/json, text/event-stream
MCP-Protocol-Version: 2026-07-28
Mcp-Method: tools/list

{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{"_meta":{"io.modelcontextprotocol/protocolVersion":"2026-07-28","io.modelcontextprotocol/clientInfo":{"name":"qualified-client","version":"1.0.0"},"io.modelcontextprotocol/clientCapabilities":{}}}}
```
Result shape: `{"jsonrpc":"2.0","id":1,"result":{"resultType":"complete","tools":[]}}` for an authenticated client with zero DISCOVER grants. A real tool list includes schema and name only when allowed. Calling a granted echo tool:
```json
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"example.echo","arguments":{"text":"hello"},"_meta":{"io.modelcontextprotocol/protocolVersion":"2026-07-28","io.modelcontextprotocol/clientInfo":{"name":"qualified-client","version":"1.0.0"},"io.modelcontextprotocol/clientCapabilities":{}}}}
```
HTTP requires matching Mcp-Method: tools/call and Mcp-Name: example.echo. Response on successful read-only tool:
```json
{"jsonrpc":"2.0","id":2,"result":{"resultType":"complete","content":[{"type":"text","text":"hello"}],"isError":false}}
```
For STDIO the same JSON lines are valid without headers and response is one stdout line. An application denial maps to safe error per C-004; never leak grant inventory for denied principal.

## Negative transcripts / expected behavior
- Missing MCP-Protocol-Version header (HTTP): HTTP 400; no legacy fallback.
- Header value 2025-11-25 with corresponding body: HTTP 400, -32022, data.supported=["2026-07-28"]; never initialize.
- Header 2026-07-28 but body 2025-11-25: HTTP 400 HeaderMismatch.
- Mcp-Method tools/list while body method tools/call: HTTP 400 HeaderMismatch.
- Missing/wrong Mcp-Name for tools/call: HTTP 400; no worker launch.
- Unknown method: HTTP 404 -32601.
- Unknown client credential or revoked client: DragonForge AUTH_INVALID/REVOKED, no tool visibility.
- Absent request _meta/version in STDIO: JSON-RPC error and no execution; never negotiate initialize.
- JSON-RPC response from client, batch array, duplicate JSON keys, malformed Unicode, oversized body: reject prior to dispatch.
- HTTP GET /mcp: never open legacy stream; return method-not-allowed.
- Closing HTTP response stream / STDIO notifications/cancelled: schedule cancellation but do not assert side-effect rollback.
- Unsupported extension request: not advertised and rejected, no handler execution.
- Host/Origin not allowlisted: HTTP 403 before MCP dispatch; cannot rely only on Authorization.
