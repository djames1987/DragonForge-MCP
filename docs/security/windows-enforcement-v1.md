# WIN-SEC-002 — Windows worker enforcement, exact control surfaces
Status: SELECTED DESIGN, not qualified. Extends WIN-QUAL-001 and DEC-004. Windows 10 x64 only; individual build/SKU/UBR qualification required.

## Process creation
Use CreateAppContainerProfile/DeriveAppContainerSidFromAppContainerName for unique tool-version profile, and SECURITY_CAPABILITIES in PROC_THREAD_ATTRIBUTE_SECURITY_CAPABILITIES via InitializeProcThreadAttributeList/UpdateProcThreadAttribute, STARTUPINFOEXW + EXTENDED_STARTUPINFO_PRESENT. Capabilities: empty for W0 and W1; deny tools requesting network. Create suspended, assign to Job Object with JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE and ACTIVE_PROCESS plus working-set/process-memory/CPU controls; inspect resulting token (TokenIsAppContainer, TokenAppContainerSid, TokenCapabilities, TokenIntegrityLevel, TokenPrivileges) before ResumeThread. Set explicit PROC_THREAD_ATTRIBUTE_HANDLE_LIST; clear inheritable handles and environment secrets. Failed job assignment or token verification -> terminate suspended process. CreateProcessW/AppContainer compatibility is platform-validated, not assumed; reject on unsupported invocation.
LPAC via documented less-privileged policy may be separately qualified; no silent downgrade. Never call Job Object a sandbox.

## Named pipes
Separate namespaces for owner admin pipe and per-worker IPC. CreateNamedPipeW with PIPE_REJECT_REMOTE_CLIENTS and FILE_FLAG_OVERLAPPED, unique pipe name, and owner-validated SECURITY_ATTRIBUTES descriptor built from explicit allow-only ACEs. Administrative DACL grants full access solely to gateway service SID and configured owner SID, denies ANONYMOUS LOGON / Everyone / AppContainer principals by not granting them; apply mandatory integrity label that prevents low-integrity writes. Worker pipe grants gateway identity and expected worker AppContainer package SID minimal read/write, no owner admin access. Validate remote flag, pipe instance and SD at creation; reject if security APIs unavailable.

Server authenticates admin peer by ImpersonateNamedPipeClient, OpenThreadToken, GetTokenInformation(TokenUser, TokenGroups, TokenElevationType and TokenIntegrityLevel), compares owner SID and suitable logon session, RevertToSelf on every path; CreateNamedPipe connection name/PID is NOT credential proof. For worker, verify actual AppContainer SID/token and bound launch instance using gateway-held random single-use challenge, never PID-only. If expected peer token cannot be derived from the selected Win32 API on actual supported Windows build, deny. No network pipe forwarding.

## File broker and package loader
Workers cannot open gateway SQLite, WAL/SHM, secret store, private registry, package staging or owner home by ACL. Broker permits only explicit per-call read/write capabilities bound to current grant, normalized relative scope and time-limited opaque token. Broker opens target using CreateFileW with FILE_FLAG_OPEN_REPARSE_POINT and FILE_FLAG_BACKUP_SEMANTICS where applicable, GetFinalPathNameByHandleW, GetFileInformationByHandleEx(FileIdInfo), rejects reparse attributes at each component and rechecks final volume/file ID. Deny alternate data streams, hardlinks if policy forbids, junction swaps and escaping original trusted root; handle based operations rather than reopen-by-name. Never hand arbitrary unrestricted directory handles to worker. Loader uses immutable digest-verified package snapshot, qualified interpreter/module search paths, no user writable earlier PATH/DLL directory. Windows library DLL search control SetDefaultDllDirectories and explicit AddDllDirectory only when needed. Revalidate opened stable file identities at use; if runtime dynamically imports from mutable paths, deny as ISOLATION_UNAVAILABLE.

## Evidence matrix
WQ-001 prove exact token, SID, capability list, integrity and job membership. WQ-002 try CreateFileW against DB/secret and inspect independent Win32 denied code and unchanged digest. WQ-003 RegOpenKeyExW against confidential key; WQ-004 Winsock connect/DNS external destination with OS trace; WQ-005 unauthorized admin pipe impersonation; WQ-006 foreign AppContainer to worker pipe; WQ-007 nested children/job escape; WQ-008 reparse and rename swap with ID checks; WQ-009 mutate immutable package; WQ-010 crash/timeout; WQ-011 broker scope read/write; WQ-012 DLL/script hijack and ambient resource inspection. Capture OS build, owner/worker token, Process Monitor/ETW events where available, OS codes, package digest, exact SHA and gateway audit. An application-generated ACCESS_DENIED alone is not sufficient. All unsupported/failed cases disable W0/W1, no broad full-trust fallback.

Source baseline: Microsoft AppContainer launch/identity, access tokens, named pipe security and Job Objects; qualification must independently validate exact OS APIs, DACL SDDL strings and suspended launch behavior on every supported Windows version.
